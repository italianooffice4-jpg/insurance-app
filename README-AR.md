# Aman System v11 — نسخة أندرويد (APK)

نفس الواجهة والبيانات المحلية، داخل تطبيق أندرويد (Capacitor). لا يحتاج الجهاز إنترنت للتشغيل.

## الطريقة 1 — بدون أي تثبيت على الكمبيوتر (GitHub)
1. أنشئ مستودعاً خاصاً (Private) على GitHub وارفع محتويات هذا المجلد.
2. تبويب Actions ← Build APK ← Run workflow.
3. بعد ~5–10 دقائق نزّل `AmanSystem-apk` من نتيجة التشغيل، وفيه `app-debug.apk`.

## الطريقة 2 — على ويندوز
1. ثبّت Node.js LTS و Android Studio (وافتحه مرة واحدة ليثبّت الـ SDK).
2. شغّل `build-apk.bat` (يحتاج إنترنت). الناتج: `android\app\build\outputs\apk\debug\app-debug.apk`.

## التثبيت على الموبايل
انقل الملف للجهاز وافتحه، واسمح بالتثبيت من مصدر غير معروف عند السؤال.

## الفروق عن نسخة الكمبيوتر
- المسح الضوئي المباشر، الطباعة المباشرة، وفتح المستند بالبرنامج الافتراضي: غير متاحة. بدلاً منها اختر ملفاً أو صوّر بالكاميرا من زر رفع الملف.
- المساعد الذكي (ChatGPT/Claude/Ollama) غير مفعّل في هذه النسخة.
- النسخة الاحتياطية وتصدير Excel والتقارير: تفتح قائمة المشاركة لحفظ الملف أو إرساله.
- البيانات تُحفظ داخل التطبيق على الجهاز (مستقلة عن نسخة الكمبيوتر)؛ انقلها بـ «نسخة احتياطية» ثم «استعادة نسخة».
- الـ APK الناتج موقّع بمفتاح التجربة (debug): يُثبَّت عادي، لكن للنشر على Google Play يلزم توقيع release.
